1) Fender Studio Pro manual — Macro Toolbar
   https://fenderstudiopromanual.fender.com/en/Content/Editing_Topics/Macro_Toolbar.htm
   Nội dung dùng được:
   - Macro tạo từ Macro Toolbar (chuột phải > Assign Command / tạo macro mới) hoặc Macro Organizer (New, đặt Title/Group, thêm lệnh; lệnh chạy theo thứ tự).
   - Gán phím: trong Macro Organizer chọn macro > "Shortcut" > nhập phím > Assign; hoặc Keyboard Shortcuts > tìm "macros".
   - Gán thiết bị MIDI: panel External của Console > mở device map > chuột phải nút > Assign Command > tìm "macros". Bộ điều khiển không được hỗ trợ vẫn dùng được nếu điều khiển gửi MIDI CC.
   - Mỗi macro là một file XML riêng; nút "Show Macros Folder in Explorer/Finder" mở thư mục; trang KHÔNG nêu đường dẫn cụ thể.
   - Trang không nhắc "Studio One" và không nêu tên file chạy (exe).
2) Fender Studio Pro manual — Key Commands
   https://fenderstudiopromanual.fender.com/en/Content/Fundamentals_Topics/Key_Commands.htm
   - Gán phím: Studio Pro/Options/General/Keyboard Shortcuts > tìm lệnh > nhập phím > Assign. Trùng phím thì có liên kết Show để gán lại. Có import/export "Keyboard Mapping Scheme" (file text). Không nêu vị trí file scheme. Footer: Fender Studio Pro 8.1.
3) Tìm kiếm tên chương trình/exe/thư mục dữ liệu của Fender Studio Pro trên Windows: KHÔNG tìm được nguồn xác nhận (kết quả chỉ là trang bán hàng/hỗ trợ không liên quan).
   => tên exe và thư mục dữ liệu của Fender Studio Pro: UNKNOWN. PDL mặc định `daw = Studio One.exe` (config.ini) -> BLOCKED_USER_TEST: Khói cho biết tên tiến trình thật (Task Manager > Details).
