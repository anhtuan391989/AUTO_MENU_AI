Input / Output / Sample Rate / Buffer / Latency / Test / Monitor Chưa có Engine

Chưa có Audio Engine riêng cho các mục này trong Core hiện tại — chỉ đang có lựa chọn thiết bị input ở trên (qua Web Audio). Khung giao diện dưới đây chờ nối Engine, không đại diện cho trạng thái thật.

Thông số AI Core Chưa có kênh IPC

Core/AI (ConfidenceEngine, DecisionEngine, RuleEngine...) hiện chưa có kênh IPC nào để Setup đọc/ghi (preload.js chưa expose). Đây là khung giao diện hiển thị đúng các khái niệm đang tồn tại thật trong core/ai (confidence, threshold, reaction speed), nhưng chưa kết nối được vì việc thêm hàm IPC mới nằm ngoài phạm vi "chỉ sửa UI Setup" của nhiệm vụ này.

MIDI Learn Chưa có Engine Input

Hiện tại app chỉ GỬI MIDI ra (Web MIDI Output) — chưa có Driver lắng nghe MIDI Input từ hardware, nên chưa thể "xoay Knob → Menu tự nhận CC". Khung UI dưới đây mô phỏng đúng luồng thao tác mục tiêu, chờ bổ sung MIDI Input Driver ở Core trước khi hoạt động thật.

🗄 Song Library Chưa có UI/IPC

Dữ liệu bài hát tồn tại thật ở database/songLibrary.json và data/songs.json, nhưng Setup hiện chưa có kênh nào để Import / Export / Rebuild / xem Statistics / quản lý Cache. Khung UI đặt sẵn dưới đây, vô hiệu hoá tới khi có IPC tương ứng.

💾 Backup & Restore

Sao lưu / phục hồi toàn bộ cài đặt hiện tại (đổi tên từ "LinkPro" cho đúng bản chất — logic export/import giữ nguyên, không thay đổi).

📈 Telemetry

Log thật đang được ghi tại thư mục /logs (qua electronAPI.sendTelemetry). Setup hiện chưa có công tắc bật/tắt hay trình xem log — đây là thông tin tĩnh, không phải điều khiển thật.

Developer / Debug / Performance Chưa có UI trước đây

Không tìm thấy cấu hình Developer/Debug/Performance nào trong project — để trống theo đúng yêu cầu "chỉ hiện nếu project có".
